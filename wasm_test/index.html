Koud: eerste run van een vers gecompileerde module (met een willekeurige custom section, zodat de engine niets kan hergebruiken). Warm: tweede instantie van dezelfde module, direct daarna. Factor = interpreter / compiler (groter is beter voor de compiler). Elke meting draait in een eigen Web Worker. gen1 = de Sapl-compiler die zijn eigen bron (~3.200 regels) compileert.
