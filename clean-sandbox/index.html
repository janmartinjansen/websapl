						About
					

					
				

				

					

						This is a sandbox for the Clean language.
						It allows you to experiment with the language and the libraries in the package registry.
						The whole sandbox, including compiler, code generator, and linkers, runs entirely in the browser in WebAssembly.
						For the implementation, see GitLab.
					

					

						This is experimental software.
						Please report any bugs (ideally including browser version and console logs).
					

					

						This sandbox is created by Camil Staps and maintained by TOP Software Technology.
					

					

						This is a modified copy, part of WebSapl and not maintained by TOP:
						it adds the JMVM as a second backend (Clean via abc2retag, Sapl via the self-hosted Sapl compiler gen1),
						Sapl as a second language (also on the ABC interpreter, via sapl2abc), and the 13 benchmarks in the tour.
						Please report problems with this copy to the WebSapl author, not to TOP.
						The original is at gitlab.com/clean-and-itasks/clean-sandbox.
					

					

						License: AGPL-3.0-only, as the original.
						The source of this copy is the files on this site: the JavaScript in js/ as is,
						the Clean sources of the sandbox (sandbox.icl, make.icl), and the original repository above for the compiler and code generator.
						The JMVM tools in engine/ (jmvm.wasm and the .jvb programs) belong to WebSapl.
