The Sapl Codebase & Toolchain in Hard Numbers

Every compiler stage, preprocessor, typechecker, frontend, linker, REPL and notebook library in this project is written in Sapl or Sapl+. Auditing all 1,197 tracked .cfp and .spp files separates 89,639 unique handwritten source lines from 56,369 lines of static-site copies and flattened builds.

4. Five measured code-generation backends (plus the Clean bridge)

Because the toolchain is decoupled at Stage-4 Retag (or JMVM bytecode), five code-generation backends were built and benchmarked against Clean native, Clean’s ABC interpreter and GHC -O2:

Target / BackendInput IRImplementationStatus & key finding
1. JMVM bytecode (.jmvm / .jvb) Stage-4 Retag stage5_codegen.cfp + jvb_asm.cfp (Sapl) Production. Runs natively (musttail) and in WebAssembly (switch, 150 KB uncompressed / 65 KB gzip).
2. Standalone WebAssembly (jmvm2wat / wasm_jit) JMVM bytecode jmvm2wat.py / wasm_jit.cpp Parked. 1.5× faster than the cold interpreter, but overtaken by warm V8 JIT on jmvm.wasm.
3. C from bytecode (jmvm2c) JMVM bytecode jmvm2c.py Superseded. Basic blocks as musttail C functions; kept temporaries on the VM stack (9.3 MB C, 47 s build, 442 ms gen1).
4. Clean ABC (sapl2abc) Stage-4 Retag sapl2abc.cfp (1,839 lines Sapl) & Python original Measured oracle. Runs all benchmarks and gen1 fixed point on Clean’s native cg and ABC interpreter.
5. C from Retag (sapl2c) Stage-4 Retag sapl2c.cfp & sapl_naar_c.py Active prototype. Whole functions with named variables for clang -O2 (2.9 MB C, 4.1 s build, 244 ms gen1).
Reverse bridge: abc2retag Clean .abc abc2retag.cfp (5,916 lines Sapl) & Python original Decompiles Clean stack code back into Stage-4 Retag, letting Clean use JMVM and sapl2c.
Why the Retag split kept the toolchain small: Roughly 40,000 lines of Sapl build three frontends (Core Sapl, Sapl+, Haskell lite), a Hindley-Milner typechecker, an incremental module linker, a live REPL/notebook kernel, a Clean ABC decompiler and two active code generators — all running as bytecode on a single 5,244-line active C/C++ VM runtime.
