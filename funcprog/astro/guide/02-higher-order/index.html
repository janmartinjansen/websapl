2. Higher-Order Functions & Currying

Paper Reference: Section 4 & Figures 2, 3 & 9 in the IFL paper.

In functional languages, functions are first-class citizens. Functions can be passed as arguments, returned as results, and partially applied through currying.

The twice Supercombinator

The classic higher-order function twice applies a function f twice to an argument x:

SaplHigher Order Twice (03_twice.cfp)
// JMVM Bytecode for Strict Factorial
fac:
    EVAL
    CASE 0 -> L0, _ -> L1
L0:
    PUSH_INT 1
    RET
L1:
    PUSH 0
    PUSH_INT 1
    SUB
    CALL fac
    PUSH 0
    MUL
    RET
main:
    PUSH_INT 10
    CALL fac
    PRINT
    HALT

Deep Curried Chains (twicex)

When chaining higher-order applications, arity checks and partial applications are resolved efficiently on the JMVM evaluation stack:

SaplCurried Chain (04_twicex.cfp)
// JMVM Bytecode for Strict Factorial
fac:
    EVAL
    CASE 0 -> L0, _ -> L1
L0:
    PUSH_INT 1
    RET
L1:
    PUSH 0
    PUSH_INT 1
    SUB
    CALL fac
    PUSH 0
    MUL
    RET
main:
    PUSH_INT 10
    CALL fac
    PRINT
    HALT
