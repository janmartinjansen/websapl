# Cursussite: "Implementing Functional Languages"

Een losstaande, kant-en-klaar gebouwde documentatiesite (VitePress) over
het implementeren van luie functionele talen — hogere-orde-functies,
strict vs. lazy, tie-the-knot, oneindige datastructuren — met een
ingebouwde, live WebAssembly Sapl-speeltuin per hoofdstuk
(`SaplPlayground`-component, dezelfde `saplcomp.jmvm`/JMVM-runner als de
rest van WebSapl).

**Geen onderdeel van de gewone bestandsboom-workflow** — dit is een
losse, statische site, geen los te openen `.cfp`/`.spp`-bronbestand. Open
`funcprog/index.html` rechtstreeks in de browser om te starten.
